# Overcast community maps in ArcEvents

## Deadwood

Built by zzuf and Metacognitive. The original PGM configuration is by zzuf. This adaptation uses version 1.0.12. RusCrafting converted the legacy blocks to Minecraft Java 1.21.11, replaced banner lettering with plain shop signs, removed entities and gameplay payloads, and selected accessible GunGame spawns. [Original world](https://github.com/OvercastCommunity/CommunityMaps/tree/44406f03ed32e547137285bb556e68cc87294db6/ffa/deadwood) · [Authors’ map submission](https://github.com/OvercastCommunity/CommunityMaps/issues/497)

## Infection: Riot in Prison

Built by Put0veda with map additions by Shimane. This adaptation uses version 1.0.12. RusCrafting converted the legacy blocks to Minecraft Java 1.21.11, removed original entities, inventories, explosives and Infection mechanics, opened the timed release gate, labelled the four wings, and selected positions for TTT. [Original world](https://github.com/OvercastCommunity/CommunityMaps/tree/44406f03ed32e547137285bb556e68cc87294db6/arcade/infection/infection_riot_in_prison) · [Author’s map submission](https://github.com/OvercastCommunity/CommunityMaps/issues/391)
