# Apocalypse supplies, 2026-11-14

Before this change the permanent survival mode does not exist. The proposal adds no Vault/token price, payout, boost, progression purchase or currency exchange. Both currencies remain separately zero in the attached calculation. Item/XP quantities are never valued through SELL. Existing SELL and the owner's future contract transition remain unchanged.

Expedition inventories, armor, offhand and native XP belong to an isolated player journal. Starter profiles receive the source-equivalent kit once; reconnect/reentry resumes the expedition. Exit restores the original state, without exporting supplies. Generated containers are shared and finite per coordinate, not per-player login rewards. Arbitrary travel can discover further supply containers; no fixed global weekly item cap is claimed. Gun magazines use existing configured capacity and contain rounds in addition to the modeled loose rounds.

The JSON records low/base/high assumptions (1/2/4 hours, 1/5/20 players, ordinary supply openings2/8/32 and medical1/3/8 per participant-day). They are sensitivity scenarios, not observed travel or loot rates. A normal supply has loose-round EV22, beef3.5, iron2, gun0.25 and vaccine0.2; an armory/core guarantees one catalog gun. A medical container has vaccine1, bread4 and honey1. Four native guns are selected uniformly. The model reports separate item units. There is no paid progression, so a currency saving time or a priced full equipment set is inapplicable.

Anti-repeat boundaries: coordinate entitlement is journaled before materialization; an in-flight container is blocked; replacing a barrel cannot reroll. A crash exactly after the journal commit and before world materialization can consume that finite container without granting its items. The code chooses no duplicate grant on replay. Player transitions keep their origin snapshot until verified restore and durable PARKED acknowledgement. Failed pre-restore exits can recapture current gear. Ender chest access and external backend commands are blocked during the expedition.

Owned actor lethal damage removes the entity before native death reward callbacks. No money/token/quest payout API is invoked. Other plugins' possible mining/advancement/proxy integrations are not a measured zero: inspect the active HOST configuration and ledger before production activation. This release's source evidence and isolated Paper tests do not claim production economy activation. Native XP acquired inside survival remains with the expedition; original XP is restored on exit.

Decision: retain free isolated survival with finite supplies. Native tests cover original hotbar/armor/offhand restoration, expedition resume and no container refill; the calculation validates only the stated arithmetic and units. Exact Cursed Walking nested loot tables and TACZ catalog remain a documented fidelity gap.
