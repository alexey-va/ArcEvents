# Textured ammunition and Zombies economy, 2026-11-04

The two existing vendor catalogs contain 36 guns (21 Voxelspawn and 15 Gold Guns), of which 12 previously fired. The additional 24 reuse existing firearm class behavior with explicit magazine/rate overrides. Their native vendor models remain attached to their own identity, including aiming and reload; the original 12 retain their authored animated models. Acquisition, existing 12 specs, reward policies and monetary prices do not change.

Ordinary Survival/Adventure ammunition is now a visible brass cartridge, PAPER/model 24801. The native recipe turns exactly one ordinary iron nugget into one round; renamed/custom nuggets do not qualify. Legacy ordinary nuggets still load 1:1. Reload commits consumption and loaded state atomically as before. Creative remains unlimited and cannot mint paid loaded rounds. Match ammunition uses PAPER/model 24802 and match identity, so it never loads an ordinary gun.

At equal use of 100/1000/10000 rounds per player-day, item consumption before=after is 100/1000/10000 iron-nugget equivalents. For 1/5/20 players this is 700/35000/1400000 equivalents per week. These are scenarios, not measured demand. Crafting changes representation only; no refund, resale recipe, shop or free ordinary ammunition is added. Vault mint/burn before=after 0; tokens mint/burn separately before=after 0. Existing stocks/iron farms remain alternative supply. Current SELL and the planned SELL-to-contract transition remain unchanged; no current shop price is assumed.

Zombies points belong to one match and disappear on restoration. Starting items, ammunition, upgrades and armor remain event items inside the existing durable player-state escrow. They do not create persistent loot, XP, money or entitlement. Owned zombie hits use controller health, and lethal hits remove the entity without native death/reward callbacks. Arbitrary native damage to those mobs is rejected; disconnect, cancel, recovery and shutdown must clean the owned entities. This reward-isolation contract requires targeted checks; a missing reward integration observation is not proof of a live zero flow.

The new ranged variants can affect ordinary-world manual kill efficiency. Existing native armor/hurt immunity, protection cancellation and reward eligibility remain; incremental throughput has not been measured. This assessment does not turn that uncertainty into a measured zero or authorize unrelated reward changes.

Calculation: `firearms-zombies-20261104.json`; evaluated result alongside it. Source checks, delivery, runtime activation and native-client acceptance are separate evidence.

## Match-only point balance

New session unit: Zombies points, with no exchange to Vault, tokens, XP or ordinary items. Starting balance 500. Kill awards: walker 100 to the killer /50 to each remaining teammate; runner 125 /50; brute 500 /150. Each clear grants 150+25×wave per remaining player. Mystery weapon costs 650 with equal selection among eight weapons, excluding the current one. Ammunition costs 150; power upgrades cost 1000/2000/3000 (maximum 3, +35% of base damage per level); vitality costs 1500 once. All costs and benefits end with the match.

One solo run completing 5/8/10 waves, with every kill credited and no purchases, gives a gross wallet of 9400/18775/27175 points. This includes the starting balance and wave bonuses. At 1/5/20 players doing one run per day, the upper scenario uses at most 10 host-hours per day at the 30 minute session limit. It does not assume simultaneous solo matches. Purchases only destroy some of those points sooner; the remainder disappears on restoration. Mode net persistent points, Vault and tokens are all zero, each in its own unit. Co-op team assists increase local purchasing power deliberately; native mob HP and wave size scale with the 1–4 player roster. Reward quantity, cleanup and actual combat difficulty still require focused mode verification.
